# Контракт бота: Java 21 / SDK 3.5

Реализуйте `edu.arena.core.combat.CombatBot`. Один вызов `decide(CombatObservation)` возвращает один `Control`. Готовых действий «ехать к цели», «искать путь», «атаковать» или сетевых договорённостей в интерфейсе нет.

## Control

| Поле       | Значение                                                                                                                                                                                                    |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `throttle` | Конечное число −1…1: назад, остановка, вперёд. Доля текущей скорости корпуса; инерции нет.                                                                                                                  |
| `turn`     | Конечное число −1…1: доля угловой скорости корпуса. Положительный знак — по часовой стрелке.                                                                                                                |
| `aim`      | Абсолютная точка `Vec2` мира. Башня поворачивается к ней со своей ограниченной скоростью; сервер не ждёт точного наведения перед выстрелом.                                                                 |
| `fire`     | Удерживаемый запрос огня. Нужны готовое оружие, снаряд и отсутствие активного щита/защиты появления. Каждый реальный выстрел расходует один снаряд; один запрос может сработать несколько раз за своё окно. |
| `shield`   | Запрос включения щита, когда восстановление завершено. `false` не отменяет уже активный щит. Под щитом нельзя стрелять.                                                                                     |

X растёт вправо, Y вниз; углы в радианах. `Control.idle(point)` останавливает корпус, выключает запросы огня/щита и задаёт точку прицела. Это не команда движения к точке.

## CombatObservation

| Данные                                            | Что можно узнать                                                                                                                                            |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `me()`                                            | Собственное положение, скорость, корпус, башня, HP и таймеры.                                                                                               |
| `visibleTanks()`                                  | Только видимые живые танки других участников. Они все потенциально могут нанести урон.                                                                      |
| `projectiles()`                                   | Видимые снаряды; владелец снаряда может сам находиться вне обзора.                                                                                          |
| `equipment()`                                     | Собственные `ammunition`, `turretUpgrade`, `repairTicks`.                                                                                                   |
| `supplies()`                                      | Видимые ящики: `id`, `kind`, `position`, `stock`, `capacity`, `health`, `nextRefillTick`. Нулевое здоровье означает разрушение, а не доступный пустой ящик. |
| `scores()`                                        | Личные очки по слотам; отрицательный результат допустим. У пустого места значение не означает наличие игрока.                                               |
| `map()`, `rules()`                                | Статическая геометрия и текущие параметры физики.                                                                                                           |
| `self()`, `life()`, `roundId()`                   | Свой слот, номер собственной жизни, идентификатор боя. Слот не является постоянной личностью аккаунта.                                                      |
| `timing()`                                        | Исходный тик и общий интервал применения команды.                                                                                                           |
| `maxAmmunition()`, `interactionRadius()`          | Вместимость боезапаса и дальность взаимодействия с ящиком; требуется также прямая видимость.                                                                |
| `repairDurationTicks()`, `upgradedTurretFactor()` | Длительность восстановления одного HP и множитель скорости улучшенной башни.                                                                                |

Пропавший из обзора танк не обязательно погиб. Старый снимок не обновляется с сервером. Вне обзора нельзя проверить наличие или остаток расходника, даже если раньше он был известен.

## Время

Снимок N открывает общее окно для ответа. Команда применяется с `applyAtTick()` до `expiresAtTick()` исключительно. Размер периода берите из `controlPeriodTicks()`: в штатном профиле это 2 тика при 20 Гц, то есть 100 мс игрового времени. Ранний ответ не исполняется раньше остальных.

Повтор запроса не продлевает команду и не заменяет уже принятую. При отсутствии следующей команды применяется нейтральное управление. Сеть между программами, консоль и длительные вычисления не должны блокировать `decide`.

Свою текущую скорость башни вычисляйте из `rules().turretSpeed()` и `upgradedTurretFactor()`, если `equipment().turretUpgrade()` истинно. Улучшение не меняет глобальный объект правил.
# Версия соединения

SDK 3.5.1 отправляет `X-Arena-Protocol: 2.13` в каждом запросе. Сервер отклоняет другой или отсутствующий заголовок с HTTP 409 и кодом `INCOMPATIBLE_PROTOCOL` до обработки действий. Единственное исключение — чтение `GET /api/v2/info` без заголовка, чтобы узнать версию сервера. Это не разрешает регистрацию, наблюдение или управление старому клиенту. Если заголовок передан, даже запрос версии требует точного совпадения.
