# Tank Arena — исходники сервера и SDK

Java 21, версия 3.5.0, протокол 2.13. Текущий профиль — самостоятельные участники, ограниченный боезапас и личный обзор. Команд, перевозки грузов и захвата в этом профиле нет.

Откройте этот `pom.xml` в IDE. Для запуска сервера используйте `edu.arena.server.bootstrap.ServerMain` с рабочим каталогом этого Maven-проекта: по умолчанию загружается `config/combat.properties`. Для компиляции без тестов: `mvn package -Dmaven.test.skip=true`. Собранный сервер находится в `arena-server/target/arena-server.jar`.

После запуска откройте `http://127.0.0.1:8080/#teacher`, войдите с ключом из `data-independent/identity/admin-key.txt`, установите общий пароль и принимайте игроков. Новый просмотр боя — `/combat.html`.

В публичном репозитории проект студента находится на верхнем уровне, исходники сервера — в `engine/`. В полном локальном рабочем дереве также сохранён `student-kit`.

Модули: `arena-core` — модель и физика; `arena-protocol` — формат сообщений; `arena-client` — подключение и общий цикл команд; `arena-server` — авторитетный сервер и интерфейс. Старые режимы сохранены в коде, но не являются текущим заданием.

Реализованы выбранные правила 1, 2, 3, 4, 5, 9, 10, 11, 13, 19. Тесты, нагрузочные прогоны и браузерная проверка для этой версии не запускались по требованию заказчика; выполнена сборка без тестов. Интерес студентов и игровой баланс не проверены.
