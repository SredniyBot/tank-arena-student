# Колония

Твоя колония — класс `MyColony`. Каждый такт игра вызывает его метод `onTick`: колония смотрит на карту и отдаёт приказы рабочим и базе.

## Установка — один раз

1. **IntelliJ IDEA** (Community подходит) и **Git**.
2. **Где хранить проект.** Не в OneDrive: синхронизация мешает сборке и портит файлы. «Документы» и «Рабочий стол» часто лежат в OneDrive — проверь путь. Надёжно — `C:\colony`.
3. **Клонировать.** IntelliJ → **File → New → Project from Version Control** → адрес репозитория → папка, например `C:\colony`.
4. **JDK 21.** Если IntelliJ пишет, что JDK нет: **File → Project Structure → Project → SDK → Download JDK**, версия 21, любой поставщик. Права администратора не нужны.
5. Дождись, пока Maven скачает зависимости: полоса внизу окна исчезнет.

## Первый запуск

Конфигурации запуска — в списке справа вверху, рядом с ▶.

1. **«Самопроверка»** → ▶. Ждём строку «Можно играть». Если есть строка с `[X]`, сделай то, что написано после «Что сделать».
2. **«Играть»** → ▶. Колония входит в общую арену на сервере курса. В первый раз консоль спросит код с экрана преподавателя и твои фамилию с именем — токен сохранится сам. Если токен уже есть (`%USERPROFILE%\.colony\token`), вводить ничего не нужно.
3. **Смотреть арену** — в браузере: http://185.81.251.155/public/?live=1. Вход не нужен.
4. **Остановить** — красный квадрат ■. Колония остаётся на месте и ждёт.

## Где писать код

`src/main/java/student/MyColony.java`, метод `onTick`:
- `view` — что видит колония: свои рабочие и база, жилы, запас энергии, правила (`view.rules()`);
- `orders` — приказы на этот такт, одному рабочему — один.

Рядом лежит `SimpleColony.java` — простая колония, которая уже добывает и нанимает. Её можно взять за основу.

Отказанный приказ печатается в консоли с причиной, например `такт 12: рабочий 2: впереди стена`. Исключение в `onTick` игру не роняет: колония стоит этот такт, в консоли — красная строка с классом исключения и строкой твоего кода.

Что нужно помнить между тактами, храни в полях объекта, не в `static`: в тестах уровней матчи идут подряд в одной программе, и `static`-поля переходят из матча в матч.

Имя и знак колонии — в `colony.properties`. Цены и числа — в [RULES.md](RULES.md).

## Арена

Один мир на всю группу, идёт без перерыва. У каждого своё место у края карты.

- **Мирно.** Чужие рабочие проходят сквозь твоих, драк нет. Жилы не иссякают.
- **Счёт** — сколько энергии колония сдала на базу и склады. Покупки счёт не уменьшают.
- **Открыто всё:** найм, склады, завалы, кирка и сумка.
- **Программа остановлена** — колония стоит и ничего не теряет. Поправил код — перезапусти «Играть»: колония продолжит с того же места.
- Раз в 15 минут где-то на карте появляется жила на 400 энергии.

Арена — для тренировки, баллов она не даёт.

## Домашнее задание — пять уровней

Пять уровней, каждый — 2 балла, всего 10. Проходить можно в любом порядке. Прежние «шаги» заменены уровнями, баллы за них не переносятся.

| Уровень | Цель попытки: сдать на 3 картах вместе | Тактов на карте |
|---|---|---|
| 1 | 3 600 энергии | 300 |
| 2 | 6 000 | 480 |
| 3 | 3 600 | 480 |
| 4 | 16 500 | 480 |
| 5 | 4 800 | 600 |

У каждого уровня свои карты. Что на них важно, видно в повторе.

**Проверить уровень** — тест `src/test/java/student/LevelsTest.java`, по методу на уровень:

1. ▶ на полях у уровня, например у `уровень3`. Уровень играется на пяти учебных картах без просмотра, за секунды.
2. В дереве тестов — карта за картой и «итого». Итог зелёный — на пяти картах вместе сдано не меньше цели.
3. У каждой карты — ссылка «Повтор: file:///…». Она открывает матч в браузере, сервер не нужен.
4. Поправил код — **Rerun Failed Tests** над деревом: те же карты ещё раз.
5. Отладка — тот же ▶ на полях → **Debug**. Точки останова в `onTick` работают, лимит такта снят.

Учебные карты одни у всех и не меняются. Попытка идёт на новых картах.

**Посмотреть уровень в браузере** — «Играть» с аргументом `--practice 3` (**Run → Edit Configurations → «Играть» → Program arguments**): случайная карта уровня 3 в просмотре. `--practice 3 --seed 7` — та же карта ещё раз.

**Сдать** — конфигурация **«Сдать»** → ▶. Попытка идёт на сервере курса, на каждом непройденном уровне, где учебные карты вместе набирают цель. Остальные уровни пропускаются, консоль пишет почему: сколько сдано на учебных картах и сколько нужно.

- Прошёл уровень — 2 балла сразу. В таблицу курса они попадают в течение пары минут.
- Попыток — не больше 5 в сутки на уровень (сутки — по Москве).
- Попытку, которую оборвала связь, не считаем.

Срок и честность — в [RULES.md](RULES.md).

## Тесты и проверка на GitHub

`src/test/java/student/MyColonyTest.java` проверяет, что колония играет без исключений; `LevelsTest` — уровни ДЗ. Запуск — ▶ на полях рядом с классом теста.

На каждый push GitHub собирает проект и запускает `MyColonyTest` и самопроверку на Linux и Windows: вкладка **Actions** репозитория. Красная проверка — код не соберётся и у преподавателя. `LevelsTest` идёт там отдельным шагом «Уровни ДЗ»: непройденный уровень проверку не красит.

## Сдать на разбор

На разбор идёт код по тегу — неподвижной метке на коммите.

| Тег | Когда |
|---|---|
| `review-1` | Контрольная точка 1 |
| `review-2` | Контрольная точка 2 |
| `review-1b` | Повторная попытка точки 1 |

Срок — за 48 часов до твоего первого слота, точную дату назовёт преподаватель. Перед тегом: «Самопроверка» проходит, проверка в **Actions** зелёная.

В IntelliJ: **Git → New Tag** → имя тега, затем **Git → Push** с галочкой **Push tags**. В терминале:

```
git tag review-1
git push origin review-1
```

Тег не переставляй. Нашёл ошибку или опоздал — исправь, закоммить и поставь новый тег, например `review-1b`.

Мини-проект и итоговый проект — в своих репозиториях, с теми же правилами тегов: промежуточная версия — `v0.1` (у итогового ещё `v0.2`), сдача — `v1.0`. Сроки — в их заданиях.

Допуск к разбору — низкий порог: проект собирается по тегу, матч доходит до конца, колония приносит доход на открытых картах. Прогон собирает код без интернета: библиотеки и плагины Maven сверх шаблона — только из списка, который назовёт преподаватель. В прогоне колония работает в изолированном режиме: сеть, файлы, запуск программ, `System.exit` и свои потоки запрещены — попытка даёт исключение в `onTick`, а задача для общего пула (`ForkJoinPool`, `CompletableFuture`) просто не выполнится, и её ожидание закончится таймаутом такта. На такт там — 200 мс. Печатать в консоль можно. В `colony.properties` имя колонии — буквы, цифры, пробел, «.», «_», «-», до 40 знаков.

## Обновление SDK

Перед парой преподаватель обновляет этот репозиторий. Забери изменения (**Git → Update Project**), затем **Maven → Reload**. Если самопроверка пишет, что SDK устарел, сделай, что она советует.

`sdk-repo/` — SDK прямо в репозитории: Maven берёт его из этой папки.

## Если не работает

- Начни с «Самопроверки»: она проверяет Java, версию SDK, папку проекта, короткий матч и порт просмотра и называет одно действие.
- Колония на арене не двигается — проверь, что «Играть» запущена: без программы колония стоит.
- Порт просмотра занят — игра возьмёт другой и напечатает адрес.
- Кракозябры вместо русских букв бывают в `cmd.exe`. Запускай из IntelliJ.
