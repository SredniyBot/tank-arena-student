# Ваш танк на Java 21

Скачайте проект через **Code → Download ZIP** и распакуйте его либо клонируйте репозиторий средствами IDE.

Откройте `pom.xml` в IntelliJ IDEA или другой Java IDE как Maven-проект. Выберите **JDK 21** и дождитесь загрузки зависимостей. SDK арены включён в проект; для первого импорта Maven и JUnit нужен интернет.

Откройте `src/main/java/student/Main.java` и нажмите **Run** рядом с методом `main`. Скрипты и параметры запуска не нужны.

## Первый запуск

В консоли IDE последовательно введите:

1. Адрес сервера, который сообщил преподаватель.
2. Имя своего танка.
3. Пароль сервера, который сообщил преподаватель. Он общий для группы.

Клиент дождётся допуска преподавателя и подключит танк. Откройте напечатанный адрес в браузере, чтобы наблюдать бой. Ключ из `admin-key.txt` предназначен для входа преподавателя в админку; в студенческий клиент его вводить не нужно.

Исходный бот стоит на месте: не движется, не целится, не стреляет и не включает щит. Защиту при появлении и возвращение после смерти обеспечивает сервер.

Если преподаватель дал HTTP-адрес в сети аудитории, клиент попросит явно разрешить незашифрованное подключение. Для внешнего сервера нужен HTTPS.

При повторном запуске укажите тот же адрес. Пароль больше не понадобится: клиент сохраняет ваш личный ключ. Нажмите Enter в поле имени, чтобы сохранить прежнее, или введите новое. Очки принадлежат аккаунту. Ключ подключения хранится вне проекта: в домашней папке пользователя, `.tank-arena/players`. Не передавайте эти файлы другим. Смена общего пароля не затрагивает ваш аккаунт.

## Где писать код

В проекте два исходных файла:

| Файл | Назначение |
|---|---|
| `Main.java` | Запуск приложения и создание нового бота для каждой жизни |
| `MyBot.java` | Ваши решения на каждом шаге арены |

Единственный игровой контракт — `Bot.decide(Observation) → Control`. Вы получаете снимок арены и возвращаете одну команду. Какие методы, классы и состояния вам понадобятся, решаете самостоятельно.

| Данные снимка | Что находится внутри |
|---|---|
| `view.me()` | Ваш танк: положение, скорость, здоровье, направление, перезарядка и щит |
| `view.opponents()` | Живые противники |
| `view.state()` | Текущий шаг, танки, снаряды и события |
| `view.map()` | Размер поля и препятствия |
| `view.rules()` | Скорости, ограничения и длительности игровых механик |

| Поле `Control` | Команда |
|---|---|
| `throttle` | Тяга от −1 до 1 |
| `turn` | Поворот корпуса от −1 до 1 |
| `aim` | Точка на поле, к которой поворачивается башня |
| `fire` | Запрос выстрела |
| `shield` | Запрос щита |

Точка прицела, равная позиции своего танка, сохраняет направление башни. Выстрел идёт в текущем направлении башни; запрос не означает мгновенный поворот или попадание. Перезарядку, столкновения, укрытия и ограничения щита проверяет сервер. После смерти клиент создаёт новый `MyBot`: поля прежнего экземпляра не переносятся в новую жизнь.

В IDE можно перейти к определениям `Bot`, `Observation`, `Control` и других типов через **Go to Declaration**. Исходники SDK включены в комплект.

## Изменить и проверить

1. Нажмите **Stop** у запущенного `Main`.
2. Измените `MyBot.java`.
3. Запустите `src/test/java/student/MyBotTest.java` как JUnit-тест.
4. Снова запустите `Main` и проверьте поведение на общей арене.

Тесты проверяют допустимость команд в разных стартовых позициях, отсутствие живых противников и новую жизнь после респавна. Они допускают любую корректную стратегию и не требуют сохранять неподвижность. Дописывайте проверки своего поведения рядом.

В окне Maven команда **verify** запускает тесты и проверяет единый стиль Java-кода. Цель **spotless:apply** форматирует код. Оба действия доступны из IDE.

## Если что-то не работает

| Ситуация | Что проверить |
|---|---|
| IDE не видит классы SDK или JUnit | Открыт именно Maven-проект; импорт завершён; JDK выбран 21 |
| Не удаётся подключиться | Сервер работает; адрес открывается в браузере с вашего ноутбука; порт доступен |
| Пароль отклонён | Уточните текущий пароль сервера у преподавателя. Ключ из admin-key.txt предназначен для админки |
| Пароль сервера не задан | Преподавателю нужно сохранить пароль в разделе «Преподавателю» в браузере |
| Клиент ждёт допуска | Преподаватель должен принять регистрацию в админке |
| На арене нет свободного места | Дождитесь места или обратитесь к преподавателю |
| Бот ошибается в `decide` | В консоли есть тип ошибки и строка вашего кода; исправьте её и запустите `Main` заново |
| Преподаватель удалил танк с поля | Клиент не возвращает его автоматически; обсудите повторный вход с преподавателем |
| Клиент для этого сервера уже запущен | Остановите предыдущий `Main` кнопкой Stop; один аккаунт управляется одним процессом |
| Ключ повреждён или сервер его больше не узнаёт | Клиент предложит сохранить старый ключ в резервной копии и зарегистрироваться заново; сначала согласуйте это с преподавателем и уточните пароль сервера |
| Доступ отозван | Преподаватель должен восстановить прежний аккаунт; ключ и очки сохраняются |
| Бот погиб | Оставьте `Main` запущенным: сервер восстановит танк и сохранит счёт |

Полная остановка клиента прерывает связь. Обычное поражение танка её не прерывает.
