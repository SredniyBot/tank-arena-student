# Колония

Твоя колония — класс `MyColony`. Каждый такт игра вызывает его метод `onTick`: колония смотрит на карту и отдаёт приказы рабочим и базе. Первая цель — чтобы рабочий принёс энергию на базу.

## Установка — один раз

1. **IntelliJ IDEA** (Community подходит) и **Git**.
2. **Где хранить проект.** Не в OneDrive: синхронизация мешает сборке и портит файлы. «Документы» и «Рабочий стол» часто лежат в OneDrive — проверь путь. Надёжно — `C:\colony`.
3. **Клонировать.** IntelliJ → **File → New → Project from Version Control** → адрес твоего репозитория → папка, например `C:\colony`. Репозиторий закрытый: IntelliJ попросит войти в GitHub.
4. **JDK 21.** Если IntelliJ пишет, что JDK нет: **File → Project Structure → Project → SDK → Download JDK**, версия 21, любой поставщик. Права администратора не нужны.
5. Дождись, пока Maven скачает зависимости: полоса внизу окна исчезнет.

## Первый запуск

Конфигурации запуска — в списке справа вверху, рядом с ▶.

1. **«Самопроверка»** → ▶. Ждём строку «Можно играть». Если есть строка с `[X]`, сделай то, что написано после «Что сделать».
2. **«Играть»** → ▶. Матч против «бронзы» на карте `steps-4`, просмотр откроется в браузере. Не открылся — открой адрес из строки `Просмотр:` в консоли.
3. Просмотр работает, пока работает программа. Остановить — красный квадрат ■.

## Где писать код

`src/main/java/student/MyColony.java`, метод `onTick`:
- `view` — что видит колония: свои юниты и база, жилы, запас энергии, правила (`view.rules()`);
- `orders` — приказы на этот такт, одному юниту — один.

Отказанный приказ печатается в консоли с причиной, например `такт 12: рабочий 2: впереди стена`. Исключение в `onTick` игру не роняет: колония стоит этот такт, в консоли — красная строка с классом исключения и строкой твоего кода.

Что нужно помнить между тактами, храни в полях объекта, не в `static`: в тестах шагов и в лестнице матчи идут подряд в одной программе, и `static`-поля переходят из матча в матч.

Имя и знак колонии — в `colony.properties`.

**Правила сезона и справочник API** — в материалах курса: `materials/student/colony/rules.md` и `api.md`. Ссылку даст преподаватель.

## Аргументы

**Run → Edit Configurations → «Играть» → Program arguments**:

| Аргумент | Что делает |
|---|---|
| `--opponent=silver` | Соперник: `bronze`, `silver` или `past:<тег>` — твоя же колония с этого тега |
| `--map=training-2` | Карта: `training-2`, `steps-4`, `world-12` или путь к файлу `.json` |
| `--seed=7` | Зерно; с тем же зерном матч повторяется в точности |
| `--ticks=1000` | Длина матча в тактах |
| `--headless` | Без просмотра: итог в консоли, повтор в папке `replays` |

Прошлые матчи открываются в просмотре: на главной странице — список повторов.

## Лестница

**«Лестница»** → ▶: шесть матчей без просмотра — «бронза» и «серебро», зёрна 1–3. Итоги дописываются в `ladder-results.json`, личный рекорд — в консоли. Закоммить этот файл: по нему преподаватель видит, как растёт колония.

## Домашнее задание — пять шагов

Каждый шаг даёт колонии новую возможность; без неё карту шага не пройти. Шаги можно проходить в любом порядке.

| Шаг | Что нового | Вызов | Цель на каждой карте |
|---|---|---|---|
| 1. Ходка | ходить, добывать, сдавать на базу | `orders.harvest(worker.id(), Direction.EAST)` | 140 энергии за 200 тактов |
| 2. Найм | база выпускает рабочих; каждый ест 1 энергии раз в 10 тактов | `orders.produce(base.id(), UnitType.WORKER)` | 1250 за 400 тактов |
| 3. Склад | рабочий строит склад, склад принимает энергию, как база | `orders.build(worker.id(), Direction.NORTH, Building.DEPOT)` | 1200 за 400 тактов |
| 4. Завалы | рабочий разбирает завал киркой | `orders.dig(worker.id(), Direction.EAST)` | 450 за 400 тактов |
| 5. Прокачка | у базы рабочий покупает кирку или сумку | `orders.upgrade(worker.id(), Upgrade.BAG)` | 1050 за 400 тактов |

Куда шагнуть — `Pathfinder.SIMPLE` из пакета `colony.sdk`:

```java
Pathfinder.SIMPLE.next(view, worker.pos(), deposit.pos()).ifPresent(d -> orders.move(worker.id(), d));
```

**Проверить шаг** — тест `src/test/java/student/StepsTest.java`, по методу на шаг:

1. ▶ на полях у шага, например у `шаг3_Склад`. Шаг играется на пяти учебных картах без просмотра, за секунды.
2. В дереве тестов — карта за картой. Зелёная — цель есть, красная — «сдано 460 из 1200, не хватило 740».
3. Под сообщением — ссылка «Повтор: file:///…». Она открывает матч в браузере, сервер не нужен.
4. Поправил код — **Rerun Failed Tests** над деревом: те же карты ещё раз.
5. Отладка — тот же ▶ на полях → **Debug**. Точки останова в `onTick` работают, лимит такта снят.

Исключение в `onTick` тоже красит карту: в сообщении — такт, ниже — стек со строкой твоего кода. ▶ у класса — все шаги сразу.

Учебные карты одни у всех и не меняются. Попытка идёт на новых картах.

**Сдать** — конфигурация **«Сдать»** → ▶. Попытка идёт на каждом непройденном шаге, где все пять учебных карт зелёные. Шаг с красной учебной картой пропускается: «шаг 4 «Завалы»: учебные карты 2 и 5 не пройдены — сначала тесты». В консоли — строка на шаг и итог.

Попытка идёт на сервере курса: его адрес уже вписан в конфигурацию «Сдать». На каждый шаг — три новые карты, цель нужна на каждой. Пройден шаг — 1 балл сразу, в общую таблицу он попадает в течение 10 минут. Попыток — не больше 5 в сутки на шаг (по Москве), между попытками минута. Срок объявит преподаватель.

В первый раз «Сдать» спросит код с экрана преподавателя и твои фамилию с именем. Если токен у тебя уже есть (`%USERPROFILE%\.colony\token`), ничего вводить не нужно: он подходит и для ДЗ, и для мира.

Без сети `Main --submit --local` проходит попытку у тебя, отметки — в `.colony/progress.json`; в ведомость они не попадают.

## Тесты и проверка на GitHub

`src/test/java/student/MyColonyTest.java` проверяет, что колония играет без исключений; `StepsTest` — шаги ДЗ. Запуск — ▶ на полях рядом с классом теста.

На каждый push GitHub собирает проект и запускает `MyColonyTest` и самопроверку на Linux и Windows: вкладка **Actions** репозитория. Красная проверка — код не соберётся и у преподавателя. `StepsTest` идёт там отдельным шагом «Шаги ДЗ»: несделанный шаг проверку не красит.

## Сдать на разбор

На разбор идёт код по тегу — неподвижной метке на коммите.

| Тег | Когда |
|---|---|
| `review-1` | Контрольная точка 1 |
| `review-2` | Контрольная точка 2 |
| `review-1b` | Повторная попытка точки 1 |

Срок — за 48 часов до твоего первого слота, точную дату назовёт преподаватель. Перед тегом: «Самопроверка» проходит, проверка в **Actions** зелёная.

В IntelliJ: **Git → New Tag** → имя тега, затем **Git → Push** с галочкой **Push tags**. В терминале:

```
git tag review-1
git push origin review-1
```

Тег не переставляй. Нашёл ошибку или опоздал — исправь, закоммить и поставь новый тег, например `review-1b`.

Мини-проект и итоговый проект — в своих репозиториях, с теми же правилами тегов: промежуточная версия — `v0.1` (у итогового ещё `v0.2`), сдача — `v1.0`. Сроки — в их заданиях.

Допуск к разбору — низкий порог: проект собирается по тегу, матч доходит до конца, колония приносит доход на открытых картах. Место против «бронзы» в порог не входит. Прогон собирает код без интернета: библиотеки и плагины Maven сверх шаблона — только из списка, который назовёт преподаватель. В прогоне колония работает в изолированном режиме: сеть, файлы, запуск программ, `System.exit` и свои потоки запрещены — попытка даёт исключение в `onTick`, а задача для общего пула (`ForkJoinPool`, `CompletableFuture`) просто не выполнится, и её ожидание закончится таймаутом такта. На такт там — 200 мс. Печатать в консоль можно. В `colony.properties` имя колонии — буквы, цифры, пробел, «.», «_», «-», до 40 знаков.

## Мир на паре

Сервер курса — `http://185.81.251.155`. Он же принимает ДЗ.

- **Войти в мир.** Убери `#` перед строкой `server=` в `colony.properties` и запусти «Играть». Без этой строки игра локальная, как раньше; `--local` играет локально и со строкой.
- **Старый адрес работает.** Если в строке стоит прежний `http://185.81.251.116`, SDK сам поведёт на новый сервер и напишет об этом. Токен прежний, менять ничего не нужно.
- **Нет токена** — консоль спросит код с экрана преподавателя и фамилию с именем, токен сохранится сам.
- **В мире колония может только то, что ты сдал в ДЗ:** склад — шаг 3, завалы — шаг 4, прокачка — шаг 5. Консоль при входе пишет, что открыто. Сдал шаг посреди пары — перезапусти программу.
- **Поправил код** — перезапусти «Играть»: колония вернётся на своё место в мире.

`sdk-repo/` — SDK прямо в репозитории: Maven берёт его из этой папки, сайт — второй источник.

## Обновление SDK

Перед парой преподаватель меняет версию SDK в `pom.xml` твоего репозитория. Забери изменения (**Git → Update Project**), затем **Maven → Reload**. Если самопроверка пишет, что SDK устарел, сделай, что она советует.

## Если не работает

- Начни с «Самопроверки»: она проверяет Java, версию SDK, папку проекта, короткий матч и порт просмотра и называет одно действие.
- Maven не скачивает SDK — проверь интернет. В классе без интернета — см. комментарий в `pom.xml`.
- Порт просмотра занят — игра возьмёт другой и напечатает адрес.
- Кракозябры вместо русских букв бывают в `cmd.exe`. Запускай из IntelliJ.
